## 🌟 Overview

**Little Sparks** is designed specifically for small toddler hands (ages 2 to 5). Featuring **Sparky**, a cheerful golden star mascot, the app provides a safe, ad-free, positive-only educational space with clear voice narration, lively YouTube/Cocomelon-style kids songs, interactive soundboards, and post-song mini-games.

---

## 🎯 Key Features

### 1. ⭐ Meet Sparky the Star Mascot
- **Interactive Winks**: Tap Sparky on the home screen to hear cheerful greetings and see playful winks.
- **Dancing Mascot**: Sparky dances along with the rhythm during songs.
- **Celebration Jumps**: Sparky leaps with star confetti and cheers when a child earns stars!

### 2. 🎵 Rhyming Preschool Songs & Karaoke Sing-Along
- **Original & Traditional Songs**:
  - 🌈 **Rainbow Colors** (*"Red is for the apple, round and sweet..."*)
  - 🔷 **Shapes All Around** (*"Circle, circle, round and round, rolling on the ground..."*)
  - 💯 **Count to a Hundred** (*"One, two, three, four, five, count with me, so alive..."*)
  - 🔤 **The ABC Song & Phonics Fun** (*"A is for apple, a-a-apple..."*)
  - 👟 **One, Two, Buckle My Shoe**
  - 🦆 **Five Little Ducks** & 🛏️ **Ten in the Bed**
  - ⭐ **Twinkle, Twinkle, Little Star**
  - 🐮 **Old MacDonald Had a Farm** (Moo, Quack, Oink, Baa)
  - 🚌 **The Wheels on the Bus** & 🚣 **Row, Row, Row Your Boat**
  - ☀️ **Good Morning Little Sparks**
  - 🙆 **Head, Shoulders, Knees and Toes** & 👏 **If You're Happy and You Know It**
  - 🌙 **Goodnight Little Star (Calm Bedtime Lullaby)**
- **Bouncing Ball Karaoke**: Words highlight in real-time with an animated bouncing star guide.
- **Song Controls**: Play, Pause, Replay from start, Speed control (`0.8x Slow`, `1.0x Normal`, `1.2x Fast`), and Favorites (❤️).
- **Interactive Tap-Along**: Tap the screen during playback to create glowing sparkle bursts!

### 3. 🔢 1 to 100+ Interactive Number Explorer
- **Full Word Pronunciation**: Numbers are spoken as complete English words (*"sixty-seven"*, *"fifteen"*, *"ninety"*), eliminating truncation and digit-by-digit reading bugs.
- **Visual Pulse Highlight**: Tapped numbers illuminate and pulse while spoken.
- **Count Aloud Mode**: Automated continuous counting (1, 2, 3...) at a comfortable toddler pace.

### 4. 🎮 Educational Mini-Games (Post-Song Activities)
- 🧩 **Matching Pairs**: Match uppercase letters and real-world items.
- 🎨 **Find the Color**: Discover objects matching the target color (e.g. yellow sunshine items).
- ⭐ **Count the Stars**: Interactive counting from 1 to 5 with voice feedback.
- 🧠 **Memory Cards**: Flip and match cute animal friends.

### 5. 🏆 Rewards, Sticker Album & Daily Streaks
- **Sticker Collection Album**: Unlockable stickers across Letters, Numbers, Colors, Shapes, Animals, and Sparky.
- **Daily Streaks**: Encouraging streak counter (*"🔥 3 Day Streak!"*) with positive voice praise.
- **Positive-Only Feedback**: Gentle encouragement without negative sounds (*"Great job!"*, *"You did it!"*, *"Sparky is proud of you!"*).

### 6. 🌙 Calm Bedtime Mode
- Dim, starry night theme with slow, soothing lullabies (*"Twinkle Twinkle Little Star"*, *"Goodnight Little Star"*) to help toddlers wind down for sleep.

### 7. 🔒 Parent Dashboard & Ergonomics
- **Parent Gate Check**: Math challenge keeps settings safe from accidental taps.
- **Screen-Time Timer**: Daily limits (15, 20, 30, 45 minutes) with automatic gentle break reminders.
- **Progress Analytics**: Track completed songs, badges earned, and time spent.
- **64px+ Tap Targets**: Large buttons, rounded borders, and zero clutter designed for small toddler hands.

## 🚀 Getting Started

### 1. Web Version (React + TypeScript + Vite)
```bash
# Navigate to the project directory
cd C:\xampp\htdocs\ikj_system

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

### 2. Mobile App (Expo SDK 57 & Expo Go)
Run live on your physical iOS or Android device:

```bash
# Start local Metro bundler
npm start

# Or launch with network tunnel (works across all Wi-Fi networks & cellular data)
npm run tunnel
```

- **iOS**: Scan the terminal QR code with your iPhone **Camera** app and tap the prompt to open in **Expo Go**.
- **Android**: Open the **Expo Go** app and tap **Scan QR Code**.
